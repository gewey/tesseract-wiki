Service Worker PWA Engine

Last modified: Oct 20, 2026 • Author: Gewey • Section: Core Engine

The gewey.github.io platform runs as a zero-build Single Page Application (SPA) backed by a custom Service Worker (sw.js). This guarantees full offline caching and instant load times without relying on heavy npm build pipelines.

[!NOTE] Cache Strategy: The Service Worker uses a Stale-While-Revalidate pattern for assets in /js/ and /css/, while strictly adhering to Network-First for live JSON API endpoints.

Cache Registration snippet

if ('serviceWorker' in navigator) {
    navigator.serviceWorker.register('/sw.js')
        .then(reg => console.log('[PWA Engine] Registered:', reg.scope))
        .catch(err => console.error('[PWA Engine] Failed:', err));
}

Subsystem Dependencies

  • dynamichead.js — Handles global head tags & CSS injection.
  • bookmarkBuilder.js — Dynamically renders tile categories.
