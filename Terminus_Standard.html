The Terminus Standard (Lizard Brain)

The foundational contract of the Viktor Substrate. Named for Terminus, Roman god of boundary stones.

The Six Laws of Terminus

  1. Orchestration vs Calculation: CORE orchestrates. NUCLEON calculates. Never swap.
  2. Disk Access Boundary: Only QUARK touches disk. All I/O must route through subspace_link.py / QuarkIOBase.
  3. Metabolic Bridging: No circular imports. ZPM bridges all tiers; daisy-chain handles cross-SSOT imports.
  4. Path SSOT: Zero hardcoded paths. All paths resolve through DHD.get_coordinates() or terminus().
  5. Telemetry Trace: Every operation leaves an indelible signature via record_telemetry().
  6. LLM Orchestration SSOT: COMTRYA is the only compliant local LLM access surface. Direct Ollama sockets are prohibited.

Compliance Checklist

A script operating in Tesseract City is Terminus-compliant if and only if:

  • It imports directly from _TERMINUS or __ssot_*.
  • All paths are resolved via DHD.get_coordinates() (no hardcoded drive letters).
  • All file persistence uses Quark I/O abstraction.
  • Every execution traces into the canonical telemetry database via record_telemetry().
